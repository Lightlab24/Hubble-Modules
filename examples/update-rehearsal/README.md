# Update rehearsal simulator

These API 1 prereleases exercise module discovery, download, explicit activation, and rollback in an isolated Hubble2 profile. They have no device, network, or native control. Version 0.1.1-test.1 adds toggle-state while retaining set-state and active feedback. Both versions are test modules, not stable device integrations.

Run `node --test examples/update-rehearsal/*/module.test.mjs` to test both versions.
