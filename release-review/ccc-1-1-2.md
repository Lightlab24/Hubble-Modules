# CCC 1.1.2

CCC now ignores unrelated or unchanged RCP camera status messages and publishes
workspace snapshots and connection status only when their values change. This
removes redundant background updates while preserving fresh recording reports
needed to confirm recording commands.

- Adds camera-specific selection feedback for Enable / Disable Camera, including
  when a selected camera or its RCP is offline.
- Keeps the CCC workspace module Ready when local camera selection is available;
  individual camera rows continue to report connection problems.
- Uses Enable / Disable Camera, Enable / Disable All Cameras, Start Recording,
  Stop Recording, and Toggle Recording as the action names. Existing action IDs,
  camera selections, and saved settings remain compatible.
