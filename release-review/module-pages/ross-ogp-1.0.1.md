# Ross Ultrix OGP 1.0.1

Groups the routing action menu by Select Source, Select Destination, Take,
Group On/Off, Route, and Refresh Names. Existing saved action IDs, settings, and
protocol behavior are preserved.

Requires Hubble's `module-presentation-v1` capability, available in the public
Hubble 2.0.2 release. The runtime files are unchanged from 1.0.0. Grouped menus and
the module-only update were verified against a running Hubble host without a host
restart or changes to other module workers.
